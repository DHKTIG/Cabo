# CABO（卡波）玩法详解

> 资料整理日期：2026-10-29
> 来源：cabocards.com 官方规则页、豆瓣游戏条目（第二版规则差异）、什么值得买/百度系中文规则整理、BGG 社区常见变体

---

## 一、这是什么游戏

| 项目 | 说明 |
|---|---|
| 类型 | 记忆 + 轻策略 + 心理博弈的毛线桌游 |
| 人数 | 2–4 人（第一版支持 2–5 人，第二版改为 2–4 人） |
| 最佳人数 | 4 人 |
| 时长 | 单局 3–5 分钟，一整场（打到 100 分）15–25 分钟 |
| 适合年龄 | 8 岁以上 |
| 核心道具 | 一副数字牌（0–13）+ 弃牌堆 + 每人 4 张暗牌 |

**一句话规则**：每人 4 张暗牌，开局只能看其中 2 张，之后全靠记忆。想办法把手牌点数换到最低，然后喊 "CABO" 结束这一轮，点数最低者赢。

**为什么好玩**：你知道的牌会不断被打乱、被换走、被对手偷看。玩到中局经常出现"我到底还有几张 12"的集体失忆现场。

---

## 二、牌组构成

### 方案 A：官方牌组（推荐）
数字牌 0–13 各若干张，另含 1 张 Joker。实际构成按各版本略有差异，但计分口径统一：

| 牌 | 点数 |
|---|---|
| A（Ace） | 1 |
| 2 – 10 | 面值 |
| J | 11 |
| Q | 12 |
| K（♥/♣/♠） | 13 |
| **K♦（方块 K）** | **0** |
| **Joker（小王/大王）** | **0** |

> 方块 K 和 Joker 是全场最珍贵的牌，拿到等于白赚。

### 方案 B：一副标准扑克（54 张，最省事）
A=1、2–10 面值、J=11、Q=12、K=13、**方块 K=0**、**Joker=0**。
2–4 人直接用一副 54 张即可，不需要额外配件。

---

## 三、初始设置

1. 洗牌，牌堆面朝下放桌子中央，旁边留出弃牌堆位置。
2. 每人发 **4 张**牌，牌面朝下，在自己面前横排一行（或 2×2 方阵，位置固定不变）。
3. **开局偷看**：每人秘密查看自己 4 张牌中的 **2 张**（通常是"最左和最右"或"自己选 2 张"），看完立刻盖回。
   - 只能看一次，看完必须记住位置和数字。
   - 手牌顺序**不可更改**（这条很重要，交换位置会破坏记忆体系）。
4. 由庄家/上一轮输家开始，顺时针进行。

---

## 四、回合流程（核心）

轮到你时，从下面 **三个行动中选一个**：

### 行动 ①：从牌堆摸一张
摸牌后只有你看得到，然后三选一：

- **A. 直接弃掉** —— 把摸到的牌正面朝上放到弃牌堆，回合结束（摸到烂牌时的常规操作）。
- **B. 与自己一张牌交换** —— 选自己一张暗牌，把摸到的牌放进去，被换出的旧牌正面朝上弃掉。
- **C. 使用能力**（仅当摸到能力牌时）—— 发动能力后，摸到的牌弃入弃牌堆。

> 关键：**只有从牌堆摸到的牌才能发动能力**。从弃牌堆拿的牌不触发能力。

### 行动 ②：从弃牌堆顶拿一张（"交易"）
弃牌堆顶是明牌，所有人都看得见，所以这条路径是"确定收益"路线。

- **1 换 1**：拿走弃牌堆顶的牌，把自己一张牌正面朝上弃掉。
- **1 换多**：如果弃牌堆顶是 `2`，而你手上有 **两张已知的 3**，可以同时翻出两张 3 弃掉，只拿走那张 2。
  - 这是 CABO 最爽的操作：**一次清掉两张高牌，只吃进一张低牌**。

**翻错惩罚（记忆的代价）**：
- 声明 1 换 2 但翻开发现数字不一致 → 你必须**收下弃牌堆顶那张牌**，翻错的牌亮在桌上（变成明牌），并且……
- 如果涉及 **3 张及以上**的牌，惩罚再加一级：**额外从牌堆抽 1 张**，塞到自己手牌最左或最右。
- 惩罚牌会撑大你的手牌数量，直接拉高总分。

### 行动 ③：呼叫 CABO
见第六节。

## 五、能力牌（Power Cards）

摸到能力牌并弃掉时，可选择发动能力（也可以放弃）。

| 牌 | 能力 | 效果 |
|---|---|---|
| **7 / 8** | **PEEK（偷看）** | 秘密查看**自己**的一张暗牌 |
| **9 / 10** | **SPY（间谍）** | 秘密查看**任意一名对手**的一张暗牌 |
| **J / Q** | **SWAP（交换）** | 交换场上**任意两张牌**的位置（可以是对手↔对手，也可以是自己↔对手） |
| **K** | 无能力 | 纯点数牌，13 分 |

> 版本差异：不少中文自制/家庭规则里是「9–K 触发能力」，或按「9/10 偷看、J/Q 间谍、K 交换」分配。开打前跟同桌确认一套即可。官方 App 采用上表。

**SWAP 的杀伤力**：把对手手里的 0 换成自己手里的 13，而且对方不知道——这是全场最阴的一手。注意交换后两张牌的朝向状态不变（暗牌还是暗牌）。

---

## 六、呼叫 CABO

当你判断自己手牌总点数**是全场最低**时，喊 **"CABO!"**

- 你的手牌**立即锁定**，不能再动。
- 其他每位玩家**再各行动一次**（这一轮不能再喊 CABO）。
- 之后所有人翻开手牌，计分。

**平局规则**：如果喊 CABO 的人与别人并列最低，**喊的人赢**（先喊者优先）。

---

## 七、计分

每人把手牌点数相加，得到"与 CABO 的距离"。

| 情况 | 得分 |
|---|---|
| 喊 CABO 者确实是（或并列）最低 | **0 分** |
| 喊 CABO 者不是最低 | 手牌点数 **+ 10 分惩罚** |
| 其他所有玩家 | 各自手牌点数（全额计入） |

**整场结束**：累计分数**超过 100 分**时游戏结束，**总分最低者获胜**。

**100 分彩蛋（只能用一次）**：如果某轮结算后你的总分**恰好等于 100**，可以把自己的分数**重置为 50 分**。第二版规则限定**整场只能用一次**（第一版可无限次，很容易被玩坏）。

---

## 八、两种"非常规赢法"（社区流行变体）

### 1. 神风特攻队（Kamikaze）
如果你喊 CABO 时，四张手牌正好是 **两张 12 + 两张 13**（Q Q K K）：
- 你本轮记 **0 分**
- **其他每位玩家各 +50 分**

手气极差时的逆风翻盘核弹。注意：需要你先喊出 CABO 才生效。

### 2. 满分 100 减 50
见上一节。分数偏高时主动"凑 100"，相当于用一次机会换 50 分减伤。

---

## 九、结束条件汇总

一轮结束的两种触发方式：
1. 有人喊了 CABO，其余人各走一回合后结束。
2. **牌堆被摸空**（无人喊 CABO）—— 第二版规则明确：牌堆耗尽当轮立即结束并计分。

整场结束：有人累计 **> 100 分**。

## 十、第二版 vs 第一版规则差异（重要）

| 规则点 | 第一版 | 第二版 |
|---|---|---|
| 人数 | 2–5 人 | 2–4 人 |
| 从弃牌堆拿的牌 | 之后仍可暗置 | **整局保持明牌**（在谁面前就一直亮着） |
| 翻错牌惩罚 | 无额外惩罚 | 保留全部牌，每多一张不匹配的牌再多留一张 |
| 漏喊 CABO 惩罚 | −5 分 | **−10 分** |
| 计分 | 最低者固定 0 分 | 只有**喊 CABO 且最低**才 0 分，其余人全额计分 |
| 一轮结束 | 仅 CABO | CABO **或牌堆摸空** |
| 100 分重置 | 无限次 | **限一次** |

> 做电子版/教朋友时，建议直接用**第二版**规则，逻辑更自洽。

## 十一、App 版独有的"BURN（烧牌）"机制

线上版（cabocards.com）在每回合结束后加了实时反应环节，线下玩可以忽略：

- 每回合结束后，**Burn 按钮出现 5 秒**，谁先点谁触发。
- **烧自己的牌，且与弃牌堆顶同点** → 该牌弃掉，你**少一张手牌**（大赚）。
- **烧自己的牌，点数不对** → 全场看到，你**额外拿一张牌**（亏）。
- **烧对手的牌，点数对** → 该牌弃掉，你**塞给对手一张自己的牌**。
- **烧对手的牌，点数错** → 全场看到，那张牌**归你**。

## 十二、策略与技巧

1. **开局记牌要有结构**：只记 2 张，但要记"位置 + 数字 + 与相邻牌的关系"。推荐记成"左1=9，右2=0"这样的坐标。
2. **优先处理 12/13**：一张 K 顶四张 A。开局看到高牌，前两回合就想办法换掉。
3. **弃牌堆是你的提款机**：只要弃牌堆顶是 0–3，而你有已知的高牌，1 换多就是稳赚。这也是唯一"不靠运气"的得分方式。
4. **7/8（PEEK）别浪费在已知牌上**：摸到能力牌时，优先偷看**你唯一不确定的那两张**。
5. **SPY 要偷"刚被换过牌的人"**：对手刚做完 SWAP，他手里大概率有货。
6. **喊 CABO 的时机**：手牌总和 **≤ 10** 且你确定至少有一家比你不低时再喊。因为喊错是 `点数 + 10`，代价极大。粗略门槛：
   - 4 张牌总和 ≤ 8：可以喊
   - 总和 9–14：看场上气氛，通常再等一轮
   - 总和 ≥ 15：绝对别喊
7. **心理战**：故意在弃牌堆留低牌引诱对手 1 换多，然后在他翻牌时…（如果规则允许，翻错就是他亏）。
8. **记别人的弃牌**：对手从手里弃掉的每一张牌，都是他手牌信息的泄漏。谁弃了 13，说明他手上还有更烂的牌。

## 十三、速查表（贴在桌上用）

```
【发牌】每人 4 张暗牌，开局看 2 张，看完盖回，位置不变
【回合】三选一：
        ① 摸牌堆 → 弃掉 / 换自己一张 / 用能力
        ② 拿弃牌堆顶 → 1换1 或 1换多（翻错要收牌，3张以上再罚抽1张）
        ③ 喊 CABO
【能力】7/8=看自己  9/10=看对手  J/Q=换任意两张  K=无
【CABO】其他玩家各走一回合 → 全翻开计分
【计分】喊者最低=0；喊者不最低=点数+10；其他人=点数
【结束】累计 >100 分结束，最低分获胜；总分恰好 100 可重置为 50（限一次）
【彩蛋】QQKK 喊 CABO = 自己 0 分，其他人各 +50
```

## 十四、程序实现要点（伪代码）

如果要做电子版，核心状态机如下：

```
state = {
  players: [{ hand: [4 张 Card], known: [bool×4], total: int }],
  deck: [Card], discard: [Card],
  caboCaller: Player | null,
  turnsAfterCabo: int,
  phase: "peek" | "turn" | "burn" | "score" | "gameover"
}

function onTurn(player, action):
  if action == DRAW_DECK:
     card = deck.pop()
     choose: DISCARD(card) | SWAP_IN(card, index) | USE_POWER(card)
     if USE_POWER and card.value in [7,8]: peek(player, randomUnknownIndex)
     if USE_POWER and card.value in [9,10]: spy(anyOpponentCard)
     if USE_POWER and card.value in [11,12]: swap(anyTwoTableCards)
  if action == TAKE_DISCARD:
     top = discard.top
     claim = selectOwnCards(count)   # 声明要换出的牌
     if all(claim.value == top.value_of_claimed... ) # 实际是"声明的牌互相同点"
        ...
     # 校验：声明换出的牌必须彼此同点；翻开后与声明不符 → 惩罚
  if action == CALL_CABO:
     caboCaller = player; locked = true
```

**关键校验点**：
- 1 换多时，判定条件是「被换出的牌**彼此**同点」，不是「与被拿走的牌同点」。这点很多实现会写错。
- 翻错惩罚分两级：翻错 1 张 → 收下弃牌堆顶牌；翻错涉及 ≥3 张 → 再罚抽 1 张。
- CABO 后每人各走一回合，且此期间禁止再喊 CABO。
- 平局时喊者胜。
